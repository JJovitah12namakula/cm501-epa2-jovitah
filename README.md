# Campus Café — CM-501 EPA 2

Accessible two-page café website prepared from the supplied starter HTML/CSS and café content.

- index.html — menu and landing page
- menu.html — redirects to index.html for compatibility with the starter filename
- contact.html — address and labelled enquiry form
- before.css — responsive shared stylesheet
- img/ — SVG artwork used by the pages
- TEST-PROTOCOL.md — accessibility test record template

## Run locally
Open index.html in a browser.

## Before submission
1. The original contact page referenced img/contact.png, which was not included in the uploaded starter files; the broken image reference was removed.
2. The address is an example address from the starter file. Confirm the real café address before publishing.
3. The supplied form action uses a reserved .example domain. It is a placeholder; form delivery requires a real endpoint.
4. Run automated and manual tests and enter actual results in TEST-PROTOCOL.md. Do not claim tests or peer testing you have not performed.
5. Review the changes and ensure you can explain them for the oral defence.
